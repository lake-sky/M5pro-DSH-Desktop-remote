# 05 — AI 自由职业服务 (freelance-services)

以**个人时间 + AI 提效**为核心交付物的可计费服务。常见方向：
- AI 文案 / 营销 / 翻译
- AI 绘画 / 设计 / 视频剪辑
- AI 代码外包 / 全栈开发
- AI 咨询 / 培训
- 自动化脚本（爬虫、办公自动化）

## 子目录约定

- 命名 `服务-客户群`，例如 `ai-copywriting-for-ecommerce` `ai-bugfix-fiverr`。
- 客户合同、报价单、交付物（脱敏版）放 `assets/cases/<client>/`。
