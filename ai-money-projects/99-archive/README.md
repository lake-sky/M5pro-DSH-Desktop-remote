# 99 — 已归档项目 (archive)

存放以下几类项目：
- ❌ **killed** —— 主动放弃，跑不通。
- 📦 **archived** —— 已稳定跑通，转交他人 / 自动化稳定运行不再需要单独维护。
- 🧊 **on-hold** —— 长期搁置，未来可能复活。

> 归档**不是删除**：原项目目录与文档保持原样迁移过来，仅补一行「归档原因」。这是个人最大的「判断力训练集」。

## 归档流程

1. 把整个项目目录 `mv` 到本目录下合适子文件夹（建议按年份/季度分子目录）。
2. 在项目 `README.md` 顶部把状态改为 `📦 archived` 或 `❌ killed`。
3. 在项目 `07-review.md` 补完复盘。
4. 在本 README 索引中补一行。
5. 如果复盘中有可复用方法，抽取到 `../../skills/`。
