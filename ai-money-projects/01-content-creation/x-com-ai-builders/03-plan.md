# 03. 计划 — 90 天 MVP 路线图

> MVP 不需要完美，但必须有「砍掉的清单」和「验收标准」。

## 一、MVP 范围

### 1.1 必须有（Must have, M0–M1）

- [ ] **X 账号人设三件套**：handle、bio、头图、置顶帖 v1。
- [ ] **每周 5 条**内容节奏（3 短帖 + 1 长 thread + 1 长文）。
- [ ] **AI 协作 SOP v1**：选题 → AI 草稿 → 我润色 → 配图 → 排程发布。
- [ ] **基础数据看板**：每周日自动统计 impressions、engagement、follower 净增、链接点击。
- [ ] **第一条 affiliate 链接**（评测 1 个 AI 工具，挂联盟链接）。

### 1.2 可以有（Nice to have, M2–M3）

- [ ] Newsletter 同步。
- [ ] 与其他 AI Builder 互推联盟。
- [ ] 长文同步到 Medium / 个人博客。
- [ ] 第一个数字产品（Gumroad prompt 模板）。

### 1.3 不要有（Won't have in v1）

- ❌ 任何付费投放（避免买粉与限流）。
- ❌ 多账号矩阵（先单账号把 SOP 跑通）。
- ❌ 短视频 / 直播（X 不是主战场）。
- ❌ 中文+英文双语同步运营（先单语：英文主，中文每月 1 条长文同步）。
- ❌ 自建 SaaS（v1 阶段先做内容，不做工具）。

## 二、里程碑

| 阶段 | 时间窗口 | 验收标准 |
| --- | --- | --- |
| M0 立项 + 调研 | 第 1 周 | `02-research.md` 完成；账号注册、bio 就位 |
| M1 MVP 跑通 30 条 | 第 2–4 周 | 累计发 30 条；进入 ≥ 1 条"放大帖"（>1k impressions） |
| M2 内测：1k 粉 | 第 5–8 周 | followers ≥ 1k；首条 affiliate 真实成交 ≥ 1 单 |
| M3 商业化：首笔 $100 | 第 9–12 周 | 累计净收入 ≥ $100；上线第 1 个 Gumroad 数字产品 |
| M4 稳态运营 | 第 13+ 周 | 90 天总 ROI 转正；自动化 ≥ 70% 内容生产 |

## 三、时间投入

- **每周可用时间**：约 10 小时（工作日每晚 1h + 周末 2h）
- **截止日期**：M3 = 2026-01-10
- **关键路径上的瓶颈**：
  - 选题（依赖每日刷 X 30 分钟）
  - 润色（依赖 native speaker 训练样本积累）
  - 数据分析（X API 申请可能拖延）

## 五、技术选型理由

- **X API v2 Basic 而非 Pro**：Pro $5,000/月 太贵，Basic $100/月 足够做"读 + 发"。
- **Hypefury 而非 Buffer**：Hypefury 有 AI 改写 + 自动 evergreen 循环，对 X 优化更好。
- **n8n 而非 Make**：开源、可自部署、调试透明。
- **本地 SQLite 而非云数据库**：单账号数据量小（<10w 行/月），本地足够。
- **Notion 而非 Airtable**：与现有工作区已有 Notion 习惯。

## 六、停损线

- 第 30 天：累计 impressions < 1,000 → **暂停**一周复盘选题。
- 第 60 天：followers < 100 → **暂停**两周，重新做人设。
- 第 90 天：净收入 < $100 → **暂停主项目 4 周**，把精力转入 03-digital-products 收尾。
- 任意时刻：被 X 限流且 7 天内无法恢复 → **立即备份全部内容**，暂停到 Bluesky/Mastodon。
