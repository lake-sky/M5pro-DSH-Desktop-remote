# /assets — 品牌资料、截图、财务

本目录存放**非内容产物**的辅助资产：品牌视觉、合规文件、收入截图、调研数据等。

## 目录约定

| 子目录 | 用途 | 入库注意事项 |
| --- | --- | --- |
| `brand/` | 头像、头图、配色、字体 | 入库 |
| `finance/` | 收入/支出报表、合同、Stripe 截图 | **脱敏后**入库，敏感字段打码 |
| `screenshots/` | 关键运营截图（X 数据面板、收入、用户反馈） | 脱敏后入库 |
| `research/` | 竞品分析、算法变动观察表 | 入库（引用即可） |

## 文件命名

```text
YYYY-MM-DD__<description>__v<n>.<ext>
# 示例：2025-10-15__x-dashboard-month1__v1.png
```

## 隐私规则

- **任何含真实姓名 / 邮箱 / 手机号 / 银行账号的截图必须打码**。
- 收入截图允许公开具体金额（与"build-in-public"人设一致），但**银行账号后 4 位、收款人姓名**必打码。
- 用户私信 / 评论截图：删去对方 handle 与头像（除非对方明确同意公开）。
