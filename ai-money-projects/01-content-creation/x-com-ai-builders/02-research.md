## 1. 市场

- **TAM（潜在市场）**：X 月活 6 亿+（2024 公开数据），英文内容创作者基数千万级；AI 工具相关创作者目测 5–10 万。
- **SAM（可服务市场）**：以"AI + Build-in-Public"为垂类的活跃账号，2024 年 H1 估计 5k–10k 头部 + 30k–50k 长尾。
- **SOM（初期可获取）**：90 天做到 1k followers、180 天 5k followers；按"放大帖"长尾流量，3 个月累计曝光 50w–200w。
- **增长趋势**：**强增长**。
  - X 内部正在重点推 Premium（变现分账）+ Communities（社群）+ 长文（Articles）三类产品。
  - 第三方机构统计，2024 年 X 上"AI"关键词日均提及量同比 +180%。
  - 蓝海仍存在："AI + 真实数字（收入/用户/留存）"型账号远少于"AI + 鸡汤/工具罗列"型。

## 4. 定价与变现假设

- **目标客单价**：
  - affiliate 单笔 $20–100（按工具不同）
  - 自有产品 $19–49 一次性 或 $9–29/月订阅
- **转化漏斗假设**：
  - 帖曝光 → profile click ≈ 0.5–1.5%
  - profile click → follow ≈ 5–15%
  - 关注者 → affiliate 点击 ≈ 0.5–2%/月
  - 点击 → 付费 ≈ 5–15%
  - 综合：每 1k followers 月度变现潜力 $20–150（保守）
- **3 个月收入预测**（保守 / 中性 / 乐观）：
  - 保守 $30 / $200 / $1,000
  - 中性 $200 / $1,000 / $5,000
  - 乐观 $1,000 / $5,000 / $20,000
- **6 个月收入预测**：
  - 保守 $500 / 中性 $3,000 / 乐观 $20,000

## 5. 成本与门槛

- **AI API 月成本**（按 30 条/月 + 数据分析）：
  - Claude / GPT-4o：~$20–60
  - Midjourney：~$30
  - 合计 $50–90
- **服务器 / 第三方服务**：
  - X API Basic $100/月（必选，用于数据抓取与监控）
  - Hypefury 或 Buffer：~$20/月
  - n8n 自部署：~$5/月
- **支付与税务**：Wise / Stripe / Gumroad 抽成约 5–10%
- **冷启动成本**：
  - 时间：每天 1–2 小时
  - 设计（头图、置顶帖视觉）：可 AI 出图，~$0–10
  - 启动资金 0（不投流，纯内容）

## 6. 风险

| 风险 | 等级 | 应对策略 |
| --- | --- | --- |
| 平台限流/封号 | 中 | 不买粉、不刷量、不群发；多设备活跃 |
| 算法/政策变化 | 高 | 多渠道备份（Newsletter、博客、Mastodon、Bluesky） |
| 模型输出"AI 味" | 高 | 强制人工 native speaker 润色 + 个人 voice 训练样本 |
| 变现距离远 | 中 | 早期就挂 affiliate；后期上自有产品 |
| 自身精力 | 中 | 内容流水线化、批量化，AI 提效 |
| 合规（affiliate disclosure） | 低 | 每条带 #ad 标签，遵守 FTC |
| 个人信息泄露 | 中 | 用独立 handle，bio 不放真名/公司 |

## 7. 调研结论

- **是否立项**：是（转入 `🛠 building` 阶段准备 MVP）
- **立项理由**（3 句话内）：
  1. X 仍是 AI 创作者**杠杆最高**、**离用户最近**的公开阵地，与现有 ai-money-projects 矩阵强协同。
  2. AI 工具已能**显著降低内容生产成本**（草稿、翻译、视觉、数据分析），单人可持续。
  3. 冷启动成本极低（时间为主），且失败信号来得快（30 天能判断是否值得继续）。
- **必须验证的 1 个关键假设**：
  - **"AI 协作生产的 X 内容，在 90 天内能否带来累计 ≥ 1k 真粉 + ≥ $100 净收入"**——如不达标，暂停并复盘。
