# tech-books-project（技术类书籍项目）

技术类书籍的写作项目区。与 [creative-project/](../creative-project/)（创意写作）并列：这里放非虚构、技术实践类的书籍项目。

## 目录索引

| 目录 | 说明 |
| --- | --- |
| [language-models-from-scratch/](language-models-from-scratch/) | 技术实践书：《从零构建语言模型》（大语言模型 / 小语言模型） |

## 组织约定

- 每本书一个子目录，目录名用英文 kebab-case，并各自维护一份 `README.md`（用途 + 索引）。
- 单本书内部按需分设：`manuscript/`（正文）、`code/`（配套代码）、`figures/`（图表）、`references/`（参考资料）——按需创建，创建后在本 README 与该书 README 同步登记。
- 目录命名规则与版本控制规则见 [根 README](../README.md)。
