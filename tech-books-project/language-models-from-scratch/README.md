# language-models-from-scratch（从零构建语言模型）

技术实践类书籍项目：《从零构建语言模型》——面向**大语言模型（LLM）与小语言模型（SLM）**的原理与动手实践。

## 定位

- **类型**：技术实践书（非虚构），以「能跑起来、能复现」为标准，不做纯理论综述。
- **读者**：具备 Python 基础、想真正理解语言模型如何从零搭起来的工程师与学习者。
- **覆盖**：既讲大语言模型的完整流程，也讲小语言模型（可在单机 / 消费级硬件上训练与推理），并强调两者在数据规模、算力预算、架构选择与工程取舍上的差异。

## 计划内容范围（草案，待细化）

| 部分 | 主题 |
| --- | --- |
| 基础 | 张量运算、自动求导、分词（Tokenizer）、数据表示 |
| 架构 | 注意力机制、Transformer、位置编码、归一化与残差 |
| 小语言模型 | 小数据 / 小算力下的训练策略、蒸馏与量化、端侧部署 |
| 大语言模型 | 预训练、指令微调、对齐、推理与效率优化 |
| 工程实践 | 数据管线、训练循环、评测方法、复现与调参 |
| 动手环节 | 每章配套的可运行代码与练习 |
