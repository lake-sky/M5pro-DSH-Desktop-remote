# 详细章节目录

> 状态：草案 v0.1。章号与 `manuscript/` 文件名一一对应。每章统一按下表四段式撰写，保证「实操可复现 + 坑点可检索」两个目标贯穿全书。

## 统一章节模板

| 段落 | 必含内容 |
| --- | --- |
| 本章目标 | 读完能做到什么；前置条件（硬件/显存/数据/前置章节） |
| 实操步骤 | 逐步命令 + 预期输出 + 关键参数为何这样定 |
| 坑点与解法 | `P-编号｜现象｜可能原因｜排查步骤｜解决办法｜如何预防` |
| 验收标准 | 怎么算跑通了（可量化：loss/分数/时延/显存占用） |

## 第一部分 · 跟着开源项目跑通全流程

### 第 1 章 开局：选路、硬件与预算
- 两条主线怎么选：MiniMind（个人卡、小时级、极低成本）vs nanochat（单机多卡、GPT-2 级）
- 硬件与预算核算：显存估算、云卡租金 vs 自购、spot 实例
- 环境搭建：Python / uv / CUDA / PyTorch 版本矩阵与常见冲突
- 第一个 smoke test：最小步数跑通全链路，确认环境无误
- 坑点：CUDA 与驱动不匹配、依赖冲突、显存估算偏差

### 第 2 章 数据与分词：从原始语料到训练集
- 数据来源与许可证；语料规模如何估算
- 清洗流水线：精确/近似去重、质量过滤、分片与打包
- 分词器：BPE 训练、词表大小取舍、中文与多语支持
- 坑点：评测集污染、编码错误、分词器与模型不匹配

### 第 3 章 预训练
- 结构关键参数（层数/宽度/头数）与「复杂度旋钮」思路
- 超参：学习率、批大小、序列长度、warmup、权重衰减
- 单卡与多卡并行（DDP / FSDP）的最小可用配置
- 断点续训、混合精度、梯度累积
- 判读训练曲线：什么样的 loss / val_bpb 算正常
- 坑点：loss 爆炸或不降、OOM、吞吐过低、结果不可复现

### 第 4 章 监督微调（SFT）
- 指令数据格式与对话模板
- 全参微调 vs LoRA / QLoRA 的选择依据
- 轮次与数据量：过拟合识别与早停
- 坑点：模板不匹配导致答非所问、灾难性遗忘、loss 正常但效果差

### 第 5 章 偏好对齐（精简版）
- DPO 类方法的适用边界与最小实现
- 偏好数据从哪来：人工标注与模型自造
- 坑点：对齐税（通用能力退化）、奖励作弊

### 第 6 章 评测
- 指标：loss / perplexity / 任务分数（含 nanochat 用的 DCLM CORE 口径）
- 自建评测集的方法与常见陷阱
- 与基线对比；结果波动与显著性
- 坑点：评测集污染、单指标误判、刷分与真实体验背离

### 第 7 章 推理与部署
- 推理基础：KV cache、采样参数（温度/top-p/重复惩罚）
- 速度与显存优化：量化、批处理、算子与时延权衡
- 本地服务化：CLI / WebUI / OpenAI 兼容 API
- 坑点：显存不足、首 token 慢、并发崩塌、量化掉点

### 第 8 章 使用模型
- 提示模板与上下文管理；系统提示与角色设定
- 常见输出问题定位：重复、截断、编造、过度拒答
- 把模型接进自己的工具链与工作流
- 坑点：上下文溢出、模板污染、长会话越用越慢

### 第 9 章 排错手册（第一部分汇总）
- 按「现象」检索的坑点总表，统一 `P-编号`
- 每条配排查决策树，先做什么、再做什么
- 应对上游项目版本漂移：如何锁定可复现的组合
