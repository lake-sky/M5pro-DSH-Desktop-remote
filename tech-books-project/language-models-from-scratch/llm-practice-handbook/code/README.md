# code（配套代码）

各章的配套脚本与最小可运行实验。按章分目录，目录名与 [outline.md](../outline.md) 的章号对应。

## 组织方式

```text
code/
├── ch01-getting-started/   # 第 1 章：环境自检与最小训练步压测
├── ch02-data-tokenizer/    # 第 2 章：数据清洗与分词器训练
└── ...                     # 以此类推
```

## 约定

- 每个脚本头部写清：用途、依赖、运行命令、预期输出、大致耗时与显存占用。
- 脚本尽量自包含、可独立运行，不依赖未公开数据；需要数据时给出获取方式与替代的小样本。
- 版本敏感处注明 PyTorch / transformers 等的最低版本要求。
