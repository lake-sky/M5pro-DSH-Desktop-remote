## 正文

取号机吐出的小票上印着 A 排 37 号。林淑贞把票根折了两折，塞进外套口袋，和上星期的、上上星期的叠在一起。她数过，一共十一张。

候诊区的椅子是连排的塑料椅，坐满了人，没有人说话。对面墙上的屏幕在滚号，每滚一次，就有一个人站起来，往走廊尽头那扇门走。

门后面是回声站。

三点二十分，叫到 37 号。

操作员是个年轻男人，胸牌上写着「实习」。他把表格推过来，指了指下面那行小字：「燃料类型：记忆。时长：三分钟。确认请签名。」

「签过了。」林淑贞说。

「这是第十一次，要重新签。」

她签了。

「您选哪一段？」他问，「系统会列出候选，您钩一下就行——」

「我知道怎么选。」

「好。」他往后靠了靠，「那您自己来。」

屏幕上浮出一排日期。她伸手去够，指尖停在最上面那条：二〇三九年，四月十七日。那天女儿在楼下摔了一跤，膝盖破了皮，回家哭着要创可贴。很普通的一天。她选了它。

屏幕右下角跳出一行字：**已消耗。剩余可用记忆：未知。**

「为什么是未知？」

「系统只能统计您在我们这里消耗的。」实习操作员说，「您平时自己忘掉的那些，我们不知道。」

门开了。

里面是一张桌子，两把椅子，桌上放着一部老式电话，听筒是塑料的，边缘磨得发白。

她坐下，拿起听筒。

「妈。」

「哎。」

「你吃饭了吗？」

「吃了。」

「吃的什么？」

林淑贞张了张嘴。她记得今天中午吃的什么——楼下那家面馆，牛肉面，多加了香菜。可她想不起来女儿爱吃的是哪一家。

「妈？」

「我在。」

「你哭了？」

「没有。」她把听筒换到另一只耳朵上，「你那边冷不冷？」

「不冷。」女儿说，「妈，我有点困了。」

「那你睡吧。」

「嗯。」

「囡囡。」

「嗯？」

林淑贞想说那句她每周都来说的话。十一周，十一遍。可这一遍，她想不起女儿的名字了。

听筒里传来很轻的呼吸声。屏幕上的倒计时在走，还剩四十一秒。

「妈，你还在吗？」

「在。」

「你在就好。」

三点二十三分，通话结束。

她放下听筒，站起来，开门出去。实习操作员递给她一张纸巾，她没接。

「下次什么时候来？」她问。

「随时。」他说，「不过按规定我得提醒您——」

「我知道。」

她往外走。口袋里的票根硌着大腿。走到门口，她停下来，把口袋里的票根全掏出来，数了一遍，又数了一遍。

然后她转身，走回取号机前面，按下了那个按钮。

机器嗡嗡响了一阵，吐出新的小票。

A 排 38 号。

## 技法对照（为什么这样写）

| 技法（出处） | 本文的落点 |
| --- | --- |
| **前 20% 规则**（[chapter-craft.md](../study/technique/chapter-craft.md)） | 开头三行就给出仪式（取号）与代价（十一张票根），不铺垫世界观 |
| **白描**（同上） | 「她签了。」「门开了。」——用动作代替情绪，全篇几乎不用形容词修饰人物 |
| **留白**（同上） | 结尾不写她的决定与感受，只写「按下按钮」「38 号」 |
| **意象营造**（同上） | 取号小票：十一张 → 十二张 → 38 号。同一个物贯穿，自己把代价说清楚 |
| **钩子 #3 未完成的动作 + #13 留白**（[hooks.md](../study/technique/hooks.md)） | 章末停在「38 号」，不解释 |
| **新名词首现管理**（[chapter-craft.md](../study/technique/chapter-craft.md)） | 「回声站」首现时给出**类别**（走廊尽头一扇门后的房间）与**可感知特征**（老式电话、磨白的塑料听筒），不解释原理 |
| **具体现实与物质细节**（[principles.md](../study/technique/principles.md) 第 5 条） | 塑料连排椅、磨白的话筒、递出又没接的纸巾、硌大腿的票根 |
| **AI 味自查**（[ai-flavor-checklist.md](../study/technique/ai-flavor-checklist.md)） | 无「微微／缓缓」类弱化副词；无章末总结升华；引号只用于对话；叙述以逗号长句为主，短句仅作重拍 |

### 一处刻意的取舍（值得记录的矛盾）

如果按海明威式的做法，全篇都可以用短句。但 [ai-flavor-checklist.md](../study/technique/ai-flavor-checklist.md) 的**规则 3** 明确说：中文叙述**默认写逗号长句**，短句是偶尔的孤立重拍。

本文的处理是：**以逗号长句为叙述基调，短句只用在需要「急停」的位置**（「她签了。」「门开了。」「A 排 38 号。」）。这不是折中，而是承认——**中文的呼吸节奏和英文不同，句法层面的风格移植要经过母语节奏的再校准**。

> 这条取舍本身就是一次有价值的实验记录：风格蒸馏（[author-styles/](../study/author-styles/)）落到中文正文时，**不能直接照搬句法层**。
