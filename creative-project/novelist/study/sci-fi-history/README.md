# sci-fi-history（科幻小说发展史与权威文献）

研究科幻小说这一文类的发展脉络，并汇集研究它所需的权威文献。

> 对应 study 的「素材（Material）」× 「文法（Author's Grammar）」交叉：既是为写作准备的类型史背景，也是理解类型惯例、找到自身谱系位置的线索库。

## 为什么写小说要读类型史

1. **避免无意重复**：今天想到的「天才点子」，1930 年代的纸浆杂志可能已经写完了整套。知道前人做到哪一步，才知道自己是在创新还是在重写。
2. **看清套路的成因**：每个经典设定（时间旅行、机器人、赛博空间、异星文明）都有它诞生时的技术语境和思想焦虑；理解成因，才能正用而不是空用。
3. **找到可以切入的空白**：类型史的每一次转向（黄金时代 → 新浪潮 → 赛博朋克）都是「上一代写法被写尽」的结果。转向处往往就是新作者的机会。

## 资料可信度说明

本目录初稿基于**百科条目**（英文维基 *History of science fiction*、*Chinese science fiction*，中文维基「科幻小说」）及其引用的文献整理，属于**二手资料的二次汇编**：

- 用于把握脉络、发现线索是可靠的；
- 涉及**具体年份、首创归属**（「第一部」「之父」这类断言）时，落笔前应回到 [sources.md](sources.md) 中的权威专著或原始刊物核对；
- 学术上有争议的判断，一律在正文标出争议，不装作定论。

`sources.md` 中每条文献都标了可信度：`【已核】`＝本次调研已在抓取到的资料中见到其被引用/著录；`【待核】`＝凭领域常识列出，**出版信息待查证**后方可正式引用。

## 关于「科幻起源」的争议（本目录的处理方式）

学界对科幻的起点没有共识，大致两派：

- **古代先驱说**：追溯到《吉尔伽美什史诗》、卢奇安《真实历史》、印度史诗中的飞行器、《一千零一夜》的机器人、《竹取物语》的月之公主等。
- **现代起源说**：认为科幻只能诞生于科学革命之后，1818 年玛丽·雪莱《弗兰肯斯坦》才是起点。

**本目录采取双轨记法**：古代与中世纪作品记为「先驱」（proto-science fiction），1818 年记为现代科幻的起点。写作时若需要主张某个「第一」，请先确认自己用的是哪一派的口径。
