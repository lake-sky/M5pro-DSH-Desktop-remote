# 阿西莫夫风格蒸馏

## 风格速写

- 一个想法就够：全篇围绕一条定律、一门科学或一个假设展开。
- 故事靠说话推进：人物坐下来讨论，道理越辩越明。
- 描写砍到最低：环境、外貌、心理各留一句，其余全给对话与推理。
- 结构像解谜：给前提 → 出矛盾 → 用逻辑翻面前提。
- 先立规则，再钻规则的缝：悖论即情节。

## 语言层

- **用词**：平实、透明、功能性词汇；术语第一次出现时用日常语言定义清楚。
- **句法**：短而清楚的陈述句与对白；对话一来一往，每句要么推进论证，要么暴露前提，删掉寒暄。
- **范例**：不写「实验室里气氛紧张，大家都感到不安」，而写「『如果第三定律优先，它就不该救他。』『可它救了。』『那就说明我们对第三定律的理解是错的。』」

## 结构层

- **一句话前提**：动笔前写下「一条规则 / 一个假设」，全篇情节由它的推论产生。
- **解谜结构**：呈现反常现象 → 人物提出若干解释 → 逐个排除 → 揭晓关键；答案往往是对前提的重新理解。
- **对话即动作**：把冲突放进辩论中，让「想清楚」成为故事的推进力。
- **结尾反转**：最后一段对话给出答案，同时改变读者对全篇的理解。
- **系列化短篇**：同一套规则可用多个短篇反复推演不同侧面。

## 主题层

- 规则与人的博弈：自洽的系统遇上不肯就范的具体处境。
- 理性可及：再复杂的问题，原则上都能被想明白。
- 文明的量级：以统计学、长时段眼光看历史与未来。

## 可执行指令（写作时照着做）

1. 动笔前写下一句话前提（一条规则或假设），并列出它的两条必然推论。
2. 用对话承担 80% 以上的篇幅，叙述只做必要的场景交代。
3. 每个场景至少出现一个悖论或反常，并让人物尝试解释它。
4. 删掉所有氛围描写与心理分析，除非它直接影响推理。
5. 结尾用一两句对话揭晓答案，且答案要让人重新理解开篇的前提。

## 蒸馏练习

用本风格改写下面这段素材：先定一条明确规则、用纯对话展开、删掉描写、让悖论推动情节、结尾反转。

> 素材：一家公司给客服机器人定了两条规则，某天它遇到一个同时满足两条相反要求的情况。

## 参考

《我，机器人》（三定律悖论推演）、《基地》（心理史学 + 长时段推演）、《钢穴》（科幻 + 侦探推理结构）、《夜幕降临》（单一概念驱动的短篇典范）。
