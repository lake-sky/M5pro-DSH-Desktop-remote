# 弗兰克·赫伯特风格蒸馏

## 风格速写

- 先造世界，再讲故事：世界本身自洽，人物只是它的产物。
- 用「文献引文 + 术语附录」把虚构世界学术化，可信度立刻上升。
- 多视角轮转，每个人只掌握部分真相，全景由读者自己拼。
- 叙述带预言与史诗的庄重感，让个人命运嵌进文明史。
- 环境不是背景，是真正的主角：资源与生态决定一切冲突。

## 语言层

- **用词**：庄重、凝练，略带年代感与书卷气；大量世界内部专名（地名、族名、术语、教义用语），第一次出现时让语境自解，不硬解释。
- **句法**：陈述句与格言式短句交替，人物常说出近似箴言的话；避免轻浮的网络腔。
- **范例**：不写「沙漠很可怕，缺水的环境影响了当地人」，而写一段伪文献：「『沙漠的法则只有一条：水属于能带走它的人。』——摘自《厄拉科斯生态札记》，第三卷」。

## 结构层

- **设定先行**：动笔前写一页「世界档案」——地理气候、关键资源、势力、宗教、经济与禁忌。
- **引文开篇**：每章前放一段虚构文献引文，暗示本章主题或后续走向。
- **多视角群像**：设 3–5 个视角，各章以其人物为中心，视角之间信息错位制造张力。
- **时间跨度**：允许故事跨越数十年乃至千年，用代际与传说消化时间。
- **附录装置**：以术语表、编年、档案摘录等附录补完世界（可在正文后）。

## 主题层

- 权力的技术：宗教、预言与情报都是统治工具。
- 生态的底线：任何对环境的榨取都要偿还。
- 预知与宿命：看得见未来的人，反而被未来锁死。

## 可执行指令（写作时照着做）

1. 动笔前先写一页自洽的「世界档案」（资源 / 势力 / 宗教 / 生态），全篇冲突都要能追溯到其中一项。
2. 每章开头放一段虚构文献引文，与本章内容形成呼应或反讽。
3. 用多视角轮转推进，禁止任何单一角色掌握全部真相。
4. 把环境（气候、资源、生态循环）当作一个会施压的角色来写，让它参与每一场冲突。
5. 人物语言带箴言感，重要判断用短句落下，避免长篇心理独白。

## 蒸馏练习

用本风格改写下面这段素材：先补一页世界档案，再给章节配一段虚构引文，用两个视角写同一件事，让环境成为施压者。

> 素材：一个偏远小镇控制着某种稀缺资源，外来势力想夺取它，镇上的人们意见分裂。

## 参考

《沙丘》（世界档案 + 章前引文 + 生态即角色 + 预言主题）、《沙丘神帝》（千年时间尺度与政治哲学）、《沙丘》附录与术语表（学术化装置）。
