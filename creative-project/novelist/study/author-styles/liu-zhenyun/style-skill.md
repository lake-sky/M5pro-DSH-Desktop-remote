# 刘震云风格蒸馏

## 风格速写

- 语言彻底放平：用农民说话的句子写小说，修饰词几乎为零。
- 靠「重复」和「绕」造节奏：同一句话来回说，说得越平常越有劲。
- 起点是一件极小的事（一句闲话、一个说法），终点是巨大的荒诞。
- 作者全程不评判、不抒情，让荒诞自证。
- 主角多是犟、轴、认死理的底层人，他们的执着本身即悲剧。

## 语言层

- **用词**：纯口语、日常词、乡土词；回避书面语与文艺腔；人名地名尽可能土。
- **句法**：短句、白话句，多用「他说」「我说」「他说」的对话推进；句子之间用「因为」「所以」「但是」兜圈子，绕出人物的逻辑。
- **范例**：不写「她感到无比委屈和愤怒」，而写「她说，我不是潘金莲。他说，你就是潘金莲。她说，我不是。他说，你就是。她说，我要是潘金莲，我就不得好死」。

## 结构层

- **重复递进**：让一句核心话在全篇出现多次，每次语境微变，从辩解到控诉到认命。
- **小事滚动**：从一个点（一句话、一个人名、一笔钱）起，滚雪球推进，牵出越来越多的人与机构。
- **上下两部 / 双线**：常用「出走—回归」或「前因—后果」两部结构，前后遥相呼应。
- **冷收尾**：结尾不作总结，让事件停在一个平白的事实上。

## 主题层

- 「话」的困境：人一辈子想找一句说得着的话，找不着才孤独。
- 个体对抗体系：一个人认死理，撞上一整套不认死理的流程。
- 荒诞即现实：越想讲理，越显得没理。

## 可执行指令（写作时照着做）

1. 全篇定一句「核心话」，让它反复出现 5 次以上，每次的处境不同。
2. 删光所有形容词与心理分析，情绪只从「谁说了什么、谁没说什么」里出来。
3. 起点必须极小（一句话或一件小事），把它的后果一层层放大到荒诞。
4. 叙述者保持冷静，不评论、不站队、不解释讽刺。
5. 用平白的口语写所有人，包括官员和知识分子，让腔调统一、荒诞感更强。

## 蒸馏练习

用本风格改写下面这段素材：用纯口语、设一句反复出现的核心话、让小事层层放大、结尾冷静收住、不评判。

> 素材：一个村民因为村委会写错了他家地界的一个名字，反复去镇上反映，事情越闹越大。

## 参考

《一句顶一万句》（重复与「找话」主题、两部结构）、《我不是潘金莲》（小事滚成荒诞 + 冷叙述）、《手机》（人与人之间的隔）、《温故一九四二》（史料与口语的写实）。
