# practice（蒸馏练习产出）

本目录登记 [../](../) 各 `style-skill.md` 中「蒸馏练习」的**实际产出**。

## 为什么必须有产出

[author-styles/README.md](../README.md) 方法论的第 4 步要求「附一个用该风格改写同一段素材的练习，检验风格是否真的能被复现」。没有产出，等于**没有验证**——一条「律」写在纸上，和写出来能读、删掉后能看出差别，是两回事。

## 命名与结构

`<author-slug>-<序号>-<英文短名>.md`，每份四块：

1. **目标**——本次要复现哪几条律（只选 3–5 条，全用会互相打架）；
2. **产出**——改写正文；
3. **逐条对照**——每条律落在哪一句（可核查）；
4. **可复现性检验**——删掉某句，风格是否还在；换素材，律是否还成立；再跑一遍 [AI 味自查](../../technique/ai-flavor-checklist.md)。

## 为什么所有练习共用同一段素材

素材固定为：**「古代一个负责运送贡品的小官，路上遇到意外，必须想办法按时送到京城。」**

同一件事在马伯庸手里与在海明威手里如何不同——横向对比才有意义。否则每次换素材，风格差异会被素材差异淹没。
