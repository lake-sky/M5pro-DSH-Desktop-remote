# 蒸馏练习 01：马伯庸风格（贡品运送）

> 素材：古代一个负责运送贡品的小官，路上遇到意外，必须想办法按时送到京城。
> 本次只复现四条律：**硬时限 / 承办者视角 / 细节实锚 / 章末留钩**。
> 「现代口吻讲古代事」这条律本次刻意只用一次——它最容易被滥用，也最容易变成标志性外壳（见 [../ma-boyong/style-skill.md](../ma-boyong/style-skill.md) 的边界一节）。

## 产出

离上元节还有九天。

少府监的节官李彦升手里有四十斤新漆，要在上元节前三日送到汴京。漆是宫里作画用的，过期一日，画不成；画不成，工部追究；追究下来，追究到他。

他算过三遍。寿州到汴京一千三百里。急脚递日行四百里【待核：沈括《梦溪笔谈》卷十一记「急脚递」日行四百里，「金字牌急脚递」更快】，寻常官车日行六十里。走官车要二十多天。他只有九天。

所以走水路。水路上有桥。

第九天，他把账簿摊开。漆每斤三百二十文【待核】，四十斤是一万两千八百文，折合一匹半马。马比漆轻，漆比马贵。账簿上还写着：漆桶四十斤一只，共三只，桶是铁皮封的，桶上有一道划痕。划痕是他自己划的，为了认出来是自己的漆。

雨涨了。桥断在颍口。

驿卒把一块木牌递上来，牌上写：三日内可修。修桥的匠人在三十里外。匠人姓陈。陈匠人去年修过一座桥，那座桥修好以后塌了。

李彦升把三只漆桶又数了一遍。上元节是初十。

## 逐条对照

| 律 | 落在哪一句 |
| --- | --- |
| **硬时限** | 「离上元节还有九天」→「他只有九天」→「上元节是初十」：时限三次复现，每次更紧 |
| **承办者视角（只看到自己那一层）** | 李彦升只知道里程、价钱、桶数、划痕；工部、朝廷、上元节都在他视野之外 |
| **细节实锚** | 里程、日行里程、每斤价钱、总价钱、桶重、桶材质、划痕——七个可查证或可核算的实锚（两处标【待核】） |
| **制度成本产生情节** | 「过期一日，画不成；画不成，工部追究；追究下来，追究到他」——因果链是行政链条，不是个人冲突 |
| **章末留钩** | 陈匠人修过的桥塌了；时限仍在走 |
| **现代口吻（一次）** | 「马比漆轻，漆比马贵」——用当代记账的落差制造趣味，不铺成全篇的语感 |

## 可复现性检验

1. **删「账簿一段」**：时限与断桥仍在，但制度成本消失，张力减半——说明「细节实锚」不是装饰，它承担了压力。
2. **删「陈匠人塌桥」**：读者只剩「桥断了」，麻烦没有升级；律 4 失效。
3. **换素材**（把漆换成军粮，把汴京换成洛阳）：时限 + 行政因果链 + 承办者视角仍成立 → 律可迁移。
4. **AI 味自查**：无「微微/淡淡/缓缓」；无章末升华；说明性内容全部嵌在动作与核算里；引号只承载实际印写的文字（木牌上的字）。

## 对照结论

同一素材，马伯庸的张力来自**时限与制度成本**；海明威的张力来自**省略与动作**（见 [hemingway-01-gongpin.md](hemingway-01-gongpin.md)）。《三分钟》用的是后者的句法，前者的结构——三分钟上限、取号、填表、签名、按次计费。
