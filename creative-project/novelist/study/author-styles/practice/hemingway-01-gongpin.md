# 蒸馏练习 01：海明威风格（同一素材）

> 素材：古代一个负责运送贡品的小官，路上遇到意外，必须想办法按时送到京城。
> 本次复现三条律：**冰山原则（删心理描写） / 对话承载潜台词 / 重复动作收束**。
> 注意：复现的是**律**，不是句法。按 [notes.md 的结论](../../../works/short-001-three-minutes/notes.md)与 [ai-flavor-checklist.md 规则 3](../../technique/ai-flavor-checklist.md)，中文叙述默认写逗号长句，短句只作重拍——把海明威的短句直接移植，会滑向「电报体」，那是另一种 AI 指纹。

## 产出

李彦升把账簿合上，塞进怀里。桥断在颍口，水还在涨，三只漆桶卸在泥边，桶是铁皮封的，桶上有一道他自己划的划痕。

「三日能修。」驿卒说。

「谁修。」

「陈匠人。」

「他在哪儿。」

「三十里外。」

李彦升摸了一遍那道划痕。上元节是初十，漆要在初七送到，送不到，工部追究，追究到他。水路没有别的桥。他没有算里程，他算过三遍了。

他把三只桶又数了一遍。车空了。

## 逐条对照

| 律 | 落在哪一句 |
| --- | --- |
| **冰山原则** | 「他没有算里程，他算过三遍了」——焦虑不写，只写他不做了什么 |
| **对话潜台词** | 「谁修」「他在哪儿」——问的不是桥，是自己能不能活 |
| **重复动作收束** | 「把三只桶又数了一遍」——《三分钟》的数票根是同一手法 |
| **中文节奏校准** | 叙述仍是逗号长句；「车空了。」只作一次孤立重拍 |

## 可复现性检验

1. **删对话段落**：张力骤降——冰山原则的张力来自没说的部分，对话正是「没说」的载体。
2. **加一句心理描写**（「他很着急」）：风格立刻崩，说明律起作用的是省略。
3. **换素材**（把漆换成军粮、把桥换成渡船）：重复动作收束仍成立 → 律可迁移。
4. **AI 味自查**：无弱化副词；无章末总结；形容词只有「铁皮封的」「他自己划的」这类带后果的限定。

## 与《三分钟》的关系

《三分钟》的句法层正是这一路：白描、留白、动作代替情绪。它的结构层则是马伯庸一路（硬时限 + 制度小人）。两者叠在一篇里，靠的是「不写的那部分承担重量」这条共同的律。
