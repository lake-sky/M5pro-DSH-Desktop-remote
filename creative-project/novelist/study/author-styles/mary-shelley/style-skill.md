# 玛丽·雪莱风格蒸馏

## 风格速写

- 故事套故事：用外层叙述者把内层自白装进去，声音一层比一层近。
- 让自然成为尺度：雪原、冰海、暴风雨一出现，人就变小、变孤独。
- 主题落在责任：不是造物可怕，而是创造者逃走。
- 用书信与自白写内心，情绪浓烈、带负罪感。
- 哥特意象打底：夜、闪电、墓园、火光、荒原。

## 语言层

- **用词**：浪漫派的抒情词汇（崇高、孤独、荒凉、神圣、战栗），哥特意象名词密集；避免现代口语与调侃腔。
- **句法**：长句为主，从句层层叠加，情绪随句子延展；在关键处用一个短句切断，制造顿挫。
- **范例**：不写「他后悔造出了那个东西」，而写「我望着那片无边无际的冰原，它在月光下像一块巨大的墓碑；我忽然明白，我逃开的不是他，而是我自己亲手点燃的那点光」。

## 结构层

- **框架叙事**：设一个外层叙述者（写信者 / 记录者），由他引出内层主角的自述；必要时再嵌一层（造物自己的讲述），三层声音各有语调。
- **对称结构**：创造者与造物互为镜像——一个是被爱包围却选择逃避的人，一个是被抛弃却渴望被爱的人。
- **崇高场景作节拍**：在情绪转折处安排一场极端的自然景观，用景物承担情感重量。
- **书信 / 手稿体**：用信件、日记、手稿的形式推进，让读者像在阅读一份被保存下来的证据。

## 主题层

- 创造者的责任：被造物的一切后果，最终都回到创造者身上。
- 孤独与被弃：真正的恐怖不是丑陋，而是没有任何人愿意看你。
- 知识的越界：求知本身不是罪，越过伦理边界才是。
- 他者：被造物即「他者」——它的暴戾来自被拒绝。

## 可执行指令（写作时照着做）

1. 动笔前先搭好叙事层数（外层谁在讲述、内层谁在自白），并给每层定一种语调。
2. 在情绪最重的三个位置各放一场极端自然景象（暴风雪 / 冰原 / 雷雨 / 荒原），用景物承重。
3. 用书信或手稿体推进叙述，让文本本身像是被保存下来的证据。
4. 把「创造者—造物」写成互为镜像的一对，双方各有一段完整的自白。
5. 主题落在责任与后果上：结尾不给和解，只给一个无法撤回的事实。

## 蒸馏练习

用本风格改写下面这段素材：加一层外层叙述者、用书信体、在情绪转折处写一场极端自然景象、让「造物」有完整自白、主题落在责任。

> 素材：一个研究者创造了一个具有自我意识的存在，后来因为害怕而离开了它。

## 参考

《弗兰肯斯坦》（三层嵌套叙事 + 北极冰原的崇高 + 创造者与造物互为镜像 + 书信体）、《最后一个人》（末世与孤独的抒情）、《玛蒂尔达》（第一人称自白的负罪感）。
