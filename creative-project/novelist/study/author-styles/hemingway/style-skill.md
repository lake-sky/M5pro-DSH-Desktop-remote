# 海明威风格蒸馏

## 风格速写

- 冰山原则：只写水面上的 1/8，情感全部压在水下，靠读者补全。
- 短句、单音节、动词驱动，删掉一切可以删的修饰。
- 最激烈的事件用最平的句子写，越克制越有分量。
- 对话像打乒乓球，真正的话永远在没说出口的部分。
- 主角是「有代码的人」：在压力下保持风度，不解释自己的痛。

## 语言层

- **用词**：优先单音节与日常词（man, cold, pain, good），避免抽象大词与拉丁词根；副词砍到最少，能不用就不用。
- **句法**：短句为主，用「and」串起并列的短动作（多并连）；一句一个动作或一个判断，不写复杂从句。
- **范例**：不写「他悲痛欲绝，心碎地看着她离去」，而写「他看着她走过去。她上了车。车开走了。他坐下来，等了很久。」——悲痛全在「等了很久」里。

## 结构层

- **冰山**：先在心里写全情感与动机，落笔时只保留可见的行动、对话、物件；删掉所有「他想 / 他觉得 / 他很痛苦」。
- **对话潜台词**：让两个人谈论一件无关紧要的事（一杯酒、一头白象），真正冲突在沉默与答非所问里。
- **循环与收束**：用重复的动作或意象（钓鱼、喝酒、下雪）作骨架，结尾回到开头的动作，余味在留白里。

## 主题层

- 代码英雄：在注定失败/无意义的世界里，凭「压力下的风度」保住尊严。
- 死亡、衰老、孤独、失去的一代；暴力与美的并置（斗牛、海、战地）。

## 可执行指令（写作时照着做）

1. 写完一段，先删光所有「他感到 / 他想 / 很 / 非常」，只留动作、对话、物件；情绪必须由这三样间接传达。
2. 把长从句拆成短句，用「and」连接连续动作，一句一动作。
3. 设计对话时让两人各说各的「表面话题」，把真正的冲突压在没说出口处。
4. 高潮事件用事实句平叙，不加任何评价与抒情。
5. 结尾回到一个具体、重复的动作上收笔，不做总结。

## 蒸馏练习

用本风格改写下面这段素材：删光心理描写与副词、把冲突压进对话潜台词、高潮用事实句平叙、结尾回到一个重复动作。

> 素材：一对夫妻在酒吧争论是否要做一次她不想他知道的决定。两人各怀心事，气氛紧绷，最后谁也没把话说破。

## 参考

《永别了，武器》（战地、背叛，平叙大悲）、《老人与海》（代码英雄、冰山、重复动作骨架）、《白象似的山庄》（对话潜台词的范本）、《乞力马扎罗的雪》（冰山 + 循环收束）。
