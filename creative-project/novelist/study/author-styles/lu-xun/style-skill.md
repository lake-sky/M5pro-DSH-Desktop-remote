# 鲁迅风格蒸馏

## 风格速写

- 冷叙述里藏火：表面越平静，批判越锋利。
- 白描立骨：少形容词，靠准确的名词和动词出力量。
- 用象征代替说教：把批判压进一个人物、一个物件、一个意象。
- 反讽为刃：让读者自己笑出声，再自己冷下来。
- 叙述者常是自省的「我」，不扮演全知的审判者。

## 语言层

- **用词**：白话为主，但在关键处嵌入冷峭文言词（如「罢了」「无非」「大抵」），形成「鲁迅腔」；删掉一切「很、非常、十分」类程度副词。
- **句法**：短句、硬句为主，一句一顿；抒情不写排比，写克制的一句收束。避免华丽与煽情。
- **范例**：不写「他非常痛苦」，而写「他坐了很久，灯花爆了一下」——让痛苦从动作与物件里渗出来。

## 结构层

- **象征**：选一个核心意象承载主题（精神胜利法 / 人吃人 / 铁屋子），全篇围绕它展开，结尾让意象自己说话，不解释寓意。
- **压缩**：短篇聚焦单一场景或单一冲突，人物精简，背景一笔带过，把篇幅让给关键对话与动作。
- **冷结尾**：结尾常是戛然而止的一句，或一个意味深长的动作，留白让读者补完批判。

## 主题层

- 国民性 / 精神困境：写麻木、自欺、看客。
- 启蒙与绝望的撕扯：叙述者既清醒又无力，甚至自我怀疑。
- 对被侮辱与被损害者的悲悯。

## 可执行指令（写作时照着做）

1. 全篇定一个核心象征（一个人物 / 一个物件 / 一个意象），让主题由它承载，删除所有直接点题的议论。
2. 每写完一段，删掉一半形容词；情绪只许从动作、物件、沉默里出来。
3. 在冷叙述的关键处埋一句反讽，让「说的」与「意的」相反。
4. 叙述者用第一人称，且让他带一点自罪或犹疑，不做全知裁判。
5. 结尾写一个具体的小动作或一句话后立刻收笔，不加「总而言之」式总结。

## 蒸馏练习

用本风格改写下面这段素材：选一个核心象征、删光程度副词、在关键处加一句反讽、结尾用一个动作戛然收住。

> 素材：小镇上有个屡遭挫折却总觉得自己很了不起的人，旁人对他又怜悯又嘲笑。一次他终于「胜」了，兴冲冲回去炫耀。

## 参考

《狂人日记》（「吃人」主题 + 第一人称狂人视角）、《阿Q正传》（精神胜利法象征）、《药》（人血馒头意象、双线索冷结构）、《祝福》（祥林嫂、「我」的自省与无力）、《秋夜》（「野草」式象征抒情）。
