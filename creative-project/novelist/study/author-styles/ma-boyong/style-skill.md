# 马伯庸风格蒸馏

## 风格速写

- 虚构必须长在真实细节上：让考据撑起可信度。
- 用现代口吻讲古代事，古今落差就是节奏与幽默的来源。
- 不讲大历史，讲大历史里一个具体的人要办成一件具体的事。
- 给故事设一个硬时限，让时间压力自己产生情节。
- 常从「史书一笔带过」处切入——留白最多的缝隙，想象空间最大。

## 语言层

- **用词**：叙述用当代口语，器物、官职、地名、度量衡用准确的历史专名——雅俗并置，反差即成风格。
- **句法**：短句推进、节奏快；说明性内容嵌进动作与对话里，不写教科书式段落。
- **范例**：不写「唐朝驿传系统十分发达」，而写「他掐着手指算：岭南到长安五千余里，快马昼夜兼程，一日最多三百里——荔枝三日色变，他只有不到二十天」。

## 结构层

- **硬时限**：开篇即给死亡线（十二时辰／十五日／荔枝变质期），全篇按倒计时推进。
- **单任务多阻碍**：主角只有一个目标，阻碍按「制度 / 人事 / 自然」三类层层加码。
- **钩子链**：每章末尾留一个待解问题，下一章开头先接住再加速。
- **小切口**：主角尽量选基层承办者（小吏、驿卒、匠人），让读者从「办事」视角看清整个系统。

## 主题层

- 时代的运行成本：盛世由无数琐碎的行政与后勤撑起。
- 制度与人：个体在规则缝隙里求活，既能钻空子也会被碾碎。
- 具体之人的尊严：大事记里没有名字的人，也值得被写。

## 可执行指令（写作时照着做）

1. 动笔前先为故事定一条硬时限，并把倒计时写进每一章的推进逻辑。
2. 每个场景至少放 3 个经得起查证的历史细节（物价、路程、官职、器物），让虚构挂在实锚上。
3. 主角必须是「承办具体差事」的人，不给全知视角，只让他看到自己那一层。
4. 用现代口语写古代人物的心理与吐槽，但叙述与对白里的历史专名保持准确。
5. 每章结尾留一个悬念或新麻烦，下一章开头立刻接住，不让节奏落地。

## 蒸馏练习

用本风格改写下面这段素材：设一条硬时限、给主角一个具体差事、补 3 个可查证细节、结尾留钩。

> 素材：古代一个负责运送贡品的小官，路上遇到意外，必须想办法按时送到京城。

## 参考

《长安十二时辰》（硬时限 + 单日叙事）、《长安的荔枝》（小切口 + 后勤成本 + 打工人视角）、《风起陇西》（历史缝隙中虚构）、《显微镜下的大明》（考据式细节写基层）。
