# 刘慈欣风格蒸馏

## 风格速写

- 先造概念，再写故事：一个宏大设定就是全书的主角。
- 尺度是武器：从日常一步跳到星系、宇宙、维度，落差即震撼。
- 语言只求清楚，不求漂亮；用陈述句把奇观说白。
- 视角要冷：人类不特殊，道德在生存面前让位。
- 用「如果……会怎样」的极端假设推动一切。

## 语言层

- **用词**：功能性的常用词 + 精确的科学名词与数字（光年、质量、速度、温度）；几乎不用华丽形容词。
- **句法**：陈述句为主，说明性段落可以长而清楚；概念第一次出现时给一个「通俗定义 + 一个比喻」。
- **范例**：不写「宇宙浩瀚得令人恐惧」，而写「宇宙就是一座黑暗森林，每个文明都是带枪的猎人，像幽灵般潜行于林间，轻轻拨开挡路的树枝，竭力不让脚步发出一点儿声音」。

## 结构层

- **概念引擎**：开场设计一个核心概念，全篇围绕它的后果层层推演。
- **尺度阶梯**：每推进一段就抬升一级尺度（个人 → 城市 → 行星 → 星系 → 宇宙），用尺度升级维持动力。
- **思想实验**：把人物放进极端处境，让他做完选择，剩下交给读者计算。
- **冷开场**：可用一段事实、一个概念、一条定律开场，不必以人物入场。

## 主题层

- 生存优先：文明的存续是最高价值，道德是其次的变量。
- 宇宙的冷漠：宇宙不恨你，只是没看见你。
- 代价：每一次跃迁式的进步都要求支付代价。

## 可执行指令（写作时照着做）

1. 动笔前先用一句话写下全书的核心概念，并写出它的三条必然推论。
2. 概念第一次出场时，用一个通俗比喻解释清楚，不依赖读者已有的科学知识。
3. 每章至少抬升一次尺度或代价，避免停留在人际层面。
4. 人物语言与心理尽量精简，让他们成为概念的承载者，不做过多抒情。
5. 用「假设 - 推演 - 后果」推进，结尾给出一个算得清的结论或一个更冷的悬念。

## 蒸馏练习

用本风格改写下面这段素材：先立一个核心概念、用通俗比喻解释它、把后果推到文明尺度、视角保持冷、语言只求清楚。

> 素材：科学家发现宇宙中存在一种普遍规律，能解释人类历史上所有文明的兴衰。
