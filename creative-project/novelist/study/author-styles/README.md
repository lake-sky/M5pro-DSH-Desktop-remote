# author-styles（作家风格研究 · 蒸馏）

研究中外各阶段作家的写作风格，并把他们的风格「蒸馏」成可复用的写作 skill，供写作时按需调用。

> 对应 study 的「文法（Author's Grammar）」分类：把名家风格从「读过」变成「能照着写」。

## 蒸馏方法论（本目录的核心方法）

对每位作家，产出两份文件，分工不同：

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `profile.md` | 生平、传世之作、风格概述、影响地位 | 背景资料，理解「这个人是谁、写了什么」 |
| `style-skill.md` | 蒸馏出的风格 skill | 写作时直接调用的「风格开关」 |

**蒸馏 = 把「读出来的感受」翻译成「可执行的写法规则」**。具体四步：

1. **读作品**：精读其 3–5 篇代表作，标注反复出现的语言、结构、视角特征（而不是看别人怎么评价他）。
2. **提特征**：从语言（用词/句长/节奏）、结构（叙事/视角/张力）、主题（母题/价值观）三个层面各抽 3–5 条可复现的特征。
3. **下指令**：把每条特征写成「写作时该怎么做 / 该避免什么」的祈使句，配一个可模仿的句式或段落范例。
4. **给练法**：附一个「用该风格改写同一段素材」的练习，检验风格是否真的能被复现。

> 原则：**学其律，不抄其句**。蒸馏出的是风格机制（律），不是原句；避免把某作家的标志性句子直接搬进自己的作品。

## 新增一位作家（检查清单）

1. `mkdir <author-slug>/`
2. 写 `profile.md`（生平 / 传世之作 / 风格概述 / 影响地位 / 参考）
3. 精读代表作后写 `style-skill.md`（套下方模板）
4. 在本 README 的「分类表」与「索引」登记
5. `git commit` + `git push`

## style-skill 模板

```markdown
---
name: <author-slug>-style
description: <一句话风格签名 + 适用场景，供写作时判断何时调用>
---
# <作家> 风格蒸馏

## 风格速写
<3–5 条最核心的风格特征，每条一句>

## 语言层
- 用词：<偏好/规避哪类词>
- 句法：<句长、断句、节奏>
- 范例：<可模仿的句式/段落>

## 结构层
- 叙事 / 视角 / 张力组织：<怎么做>

## 主题层
- 反复出现的母题与价值取向

## 可执行指令（写作时照着做）
1. <祈使句 1>
2. <祈使句 2>
…

## 蒸馏练习
用本风格改写以下同一段素材：<附一段中性素材>

## 参考
<作品名、篇目、来源>
```
