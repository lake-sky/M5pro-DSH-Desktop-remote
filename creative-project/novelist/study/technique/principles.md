# 基础文学原理与通俗小说共性规律

> 摘编自 [Novel-Control-Station-Skill](https://github.com/jingtai123/Novel-Control-Station-Skill)（MIT）的 `foundational-literary-principles.md` 与 `popular-fiction-common-laws.md`。
> 原文的定位是「把高信噪比的文学手艺变成**可执行的写作动作**」——本笔记保留这个取向。

## 第一部分：基础文学原理（地基）

### 1. 人的真实优先于情节方便

每个决定性节拍都要能回答三问：**此刻谁想要什么** / **什么恐惧、羞耻、亏欠或矛盾挡着他** / **为什么这是最不虚假的一步**。
若一个节拍只是因为「大纲需要」，先修人物压力，再动笔。

### 2. 表层可读，深层可复杂

复杂性只在读者仍能追踪**当前目标、当前风险、当前情感亏欠**时才被允许。
任何非线性、多线切换、结构跳跃，都必须揭示新的人物真相、主题压力或因果关系。
若一段文字需要文外的解释才读得懂——先简化表层。

### 3. 因果压力，而非事件堆叠

把每一句从「然后呢」改写成「因为」「所以」「尽管如此」。
每章至少要改变一条线的**风险等级、权力平衡或情感亏欠**。
**检验法**：若两章互换顺序而无损伤，说明因果链太弱。

### 4. 欲望、恐惧、羞耻、亏欠

每个核心人物要记录：显性欲望 / 隐性需求 / 恐惧 / 羞耻点 / 欠人或被欠的债 / 内在矛盾。
每个重要场景至少激活其中一项。**拒绝**那些只为解释、暗示或推动情节而存在的人物。

### 5. 具体的现实与物质细节

重要场景要锚定在感官、劳动、制度或流程的细节上。
即便是奇幻、象征或高概念题材，也需要成本、惯例与摩擦。
宁可**一个准确的、携带后果的世界细节**，不要装饰性描写。

### 6. 主题即压力

主题活在**选择、省略与代价**里，不在总结里。
先定义：核心问题 / 对立价值 / 反复出现的创伤或考验。
每章通过行动或拒绝，压一次价值冲突。删除那些代替了戏剧冲突的口号式句子。

### 7. 形式的必要性

视角、时态、时间顺序、章节排序，都必须**挣得**自己的复杂度。
自问：为什么是这个声音 / 为什么是这个顺序 / 什么真相只有这样才可见。
若答案只是「风格」或「新奇」——简化。

### 8. 语言健康

砍掉死的、膨胀的、假装深刻的、口号式的文字。
偏好具体名词、主动动词、**携带后果的意象**，以及情绪温度匹配的句法。
抒情语言只有在**锐化感知、张力或母题**时才保留。

### 9. 结局压力

长篇动笔前就要知道结局的**情感与道德余味**。
情节机制可以悬置，但**代价与意义的方向不能悬置**。每条活跃的线都该指向后果，而不是无尽延展。

### 10. 受控的发现

允许在已知约束内发现新东西。当写作暴露出更好的真相时：更新状态文档 → 修补所有受影响的结构文件 → 记录改了什么。
**不要让即兴跑在文档前面。**

### ❌ 拒绝信号（出现即回炉）

- 没有前置压力支撑的反转
- 漂亮但对叙事毫无作用的段落
- 主题被「解释」而非被「演出」
- 世界观与劳动、金钱、法律、仪式或肉身后果脱钩
- 制造噪音而非义务的章末钩子

## 第二部分：通俗小说共性规律（市场层）

> 原文说明：这些是从高热度与高口碑样本中蒸馏的**参考压力，不是模仿模板**。

1. **主题必须落在行动上**——只有当主题改变了一个决定、一段关系或一项代价时，它才成立。
2. **人物需要压力与运动**——每个核心人物要定义：想要什么 / 什么阻挡 / 追求要付什么代价 / 压力升高时如何反应 / 本章可行的弧光推进。**扁平的角色标签不够**。
3. **章节需要四件套：钩子、推力、局部收束、亏欠**——开篇是什么勾起好奇或张力 / 什么推动故事前进 / 什么在本章内闭合 / 什么债留到后面。若一章只是「包含了事件」，结构就是弱的。
4. **多线要互相干涉，而不是并排展示**——线之间必须碰撞、污染或改道。**不影响主线的支线就是装饰**。
5. **可读性不等于简单**——结构可以分层，表层必须清楚。信息要按「张力与理解同时最大化」的顺序抵达。
6. **记忆点**——每章至少留一个：一个带电的意象 / 一次价值碰撞 / 一次带后果的反转 / 一个改变人物观感的行动。
7. **弧光靠增量推进**——不要只在重大情节节点动人物：新的恐惧、新的勇气、新的亏欠、新的自我认识、新的关系状态，都算增量。
8. **钩子密度要匹配模式**——热度导向可以更狠地推悬念与追更感；口碑导向或慢热可以放松钩子密度。但**任何模式下，困惑、拖沓、情绪平淡都算失败**。
9. **原创性高于对标崇拜**——提取原理，不要提取外壳。若稿子读起来像「某某的某某版本」，停下来重建压力系统。
10. **合规是手艺的一部分**——绝不模仿：标志性的情节引擎、著名的揭秘顺序、招牌式人物外壳、独特的语言质感。**把每一条借鉴来的经验，转成针对自己项目的约束**。

### ❌ 失败信号

- 口号式的主题发言
- 人物按标签反应，而不是像人
- 有推进但无收束 / 有收束但无留债
- 事件很多，余味很少
- 一眼可识别的「对标 cosplay」

> 最后一条值得单独记：**合规不只是法律问题，也是手艺问题**。它与 [ai-compliance.md](../../publishing/ai-compliance.md) 的「学其律，不抄其句」是同一条原则在创作层的落地。
