# 卡文诊断与内容扩充

> 摘编自 [chinese-novelist-skill](https://github.com/PenglongHuang/chinese-novelist-skill)（MIT）的 `references/guides/content-expansion.md`。
> 用途：**写不动、写太薄、字数不够**时的操作手册。

## 一、先诊断，别急着加字

> **防注水原则**：扩充不是注水。以下扩充**无效且必须避免**——
> - 与角色情绪或情节走向无关的**风景堆砌**；
> - 不推进人物弧光的**凑字数回忆**。

| 问题 | 特征 | 首选策略 |
| --- | --- | --- |
| 场景太薄 | 只有对话，没有环境/感官 | 场景肌理充实 |
| 关键时刻太快 | 重要转折一笔带过 | 放慢（子弹时间） |
| 人物像纸片 | 只有动作，没有内心 | 内心世界展开 |
| 对话干瘪 | 只传递信息 | 对话加层 |
| 章节单薄 | 只有主线一件事 | 次要情节穿插 |
| 场景发平 | 只有视觉 | 感官维度叠加 |

## 二、六个扩充技巧

### 技巧 1：场景肌理充实

场景不只是地点，它是光线、温度、气味、声音、空间感、物品质感的综合体。**三个维度**：

1. **感官层**：视觉 + 听觉 + 触觉 + 嗅觉，**至少覆盖两到三种**；
2. **空间层**：角色在空间中的位置、移动、与其他物体的距离关系；
3. **情绪层**：环境如何**映射或反衬**角色当前的心理状态。

### 技巧 2：关键时刻放慢（子弹时间）

小说不是实时播放。重要时刻应该比实际时间**慢得多**——把一秒钟写成一整段，把一个动作分解成五个微动作，把一个念头展开成三层思维。两种手法：

- **动作分解**：把笼统动作拆成「准备—执行—意外—调整—完成」的微步骤序列；
- **思维展开**：在动作间隙插入判断、回忆、预判与情感波动。

### 技巧 3：内心世界展开

内心戏不是写「他很高兴」「她很害怕」。四种手法可单用可叠加：

1. **思维链展开**：一个念头引出下一个——A 想到 B，B 让他想到 C，C 又和 D 矛盾。人的思维是不断分叉又回旋的；
2. **感官触发记忆**：一个气味、一段旋律、一种触感自然带出回忆，**不需要刻意"闪回"**；
3. **内心对话**：角色在脑子里和自己吵架——自我质疑、自我安慰、自我欺骗；
4. **身体反应映射**：让身体先于意识反应（手在抖，于是把手藏进袖子里）。

### 技巧 4：对话加层

干瘪的对话只传递信息。加三层：

1. **动作与表情中断**：说话时人在做别的事（喝水、翻文件、整理衣领），这些动作透露真实状态；
2. **潜台词层**：说出口的话和真正想说的不是一回事，**说 A 想 B**；
3. **话题绕弯再回来**：现实中人们很少直接切入正题——先聊天气、聊食物，然后突然拐回核心话题。**这种绕弯暗示角色在酝酿勇气或寻找时机**。

### 技巧 5：次要情节穿插

次要情节像编织的暗线，从主线缝隙里穿过去。四种穿插方式：

1. **配角的小故事片段**：不用给配角完整故事线，只需一个细节，让读者觉得这人有自己的生活；
2. **暗线的一笔推进**：用一两句提到之前埋的伏笔，保持它在读者记忆中的活跃度；
3. **伏笔的自然埋设**：不经意地提到某人、某事、某物，后面再揭示其重要性；
4. **关系的微妙变化**：相隔几百字的两处细节，前后呼应出关系的位移。

> 示例（配角片段）：桌上手机亮了一下，是搭档发来的消息：「今晚吃火锅？我请。」后面跟了一个表情包，一只企鹅举着辣椒。方旭盯着那只企鹅看了三秒——**搭档以前不发表情包，是从什么时候开始用的？他想不起来。**

### 技巧 6：感官维度叠加

场景读起来「平」，常常是因为只用了视觉。**关键在于选择与场景情绪匹配的感官**：

| 题材/情绪 | 应加的感官 |
| --- | --- |
| 恐怖 | 嗅觉 + 触觉 |
| 浪漫 | 听觉 + 嗅觉 |
| 动作 | 触觉 + 听觉 |

## 三、分题材的「扩充富矿」

| 题材 | 扩充核心 | 具体策略 |
| --- | --- | --- |
| **悬疑/推理** | 让信息**以可控速度释放** | 线索分层呈现——发现一封信：先看信封（谁寄的？邮戳日期？），再抽信纸（字迹？折痕暗示读过几次？），最后才是内容。**每一层都可触发推理** |
| **言情/都市** | 把情感变化**拆成足够细的微事件** | 一次心动是持续几十秒到几分钟的过程，含身体反应、思维变化、行为掩饰、事后回味。把「她爱上他了」拆成无数微瞬间 |
| **奇幻/玄幻** | 通过**行动与体验**展示世界观 | 不写「魔法分五级」，而让角色在使用中感受等级间的差距、限制与代价——**让读者从角色额头的汗水判断这魔法有多难** |
| **历史/古风** | 让读者通过**日常生活**感受时代质感 | 衣食住行都有时代特征：一盏茶的冲泡方式、一件衣服的穿法规矩、一间屋子的陈设等级 |

## 四、扩充实操四步

1. **诊断**：对照第一节的表格，找出最薄弱的环节（可能多个并存，先解决最严重的）；
2. **选技**：选 1–3 种技巧。**不要在同一段落叠加太多手法**——每种技巧至少给两三百字的施展空间；
3. **找插入点**：扩充内容**不要全堆在章节末尾**。找叙事节奏中自然的「喘息点」——场景转换处、对话间隙、角色独处的时刻；
4. **通读复检**：用下面四问检验每一处扩充。

### 扩充有效性四问

1. 扩充部分**是否推进了故事**？（即使不是主线，也应推进人物认知、关系变化或氛围营造）
2. **删掉它，故事是否变差**？——如果删掉完全没影响，那就是注水。

> 后两问（原表未列全）本质相同：**扩充必须留下痕迹**。这与 [ai-flavor-checklist.md](ai-flavor-checklist.md) 的「删掉任何一句会影响理解吗」是同一把尺子，只是方向相反——**一个用来删，一个用来加**。
