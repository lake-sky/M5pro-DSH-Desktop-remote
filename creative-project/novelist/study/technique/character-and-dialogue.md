# 人物构造与对话写法

> 摘编自 [Novel-Control-Station-Skill](https://github.com/jingtai123/Novel-Control-Station-Skill)（MIT）的 `character-construction-methods.md` 与 `dialogue-writing-rules.md`。
> 原文取向：把人物设计变成**行为压力**，而不是履历墙纸。

## 第一部分：人物构造

### 1. 从压力建模，不从标签建模

每个重要人物都要定义：**显性欲望 / 隐性需求 / 主要障碍 / 追求的代价 / 恐惧 / 羞耻点 / 情感或道德亏欠 / 内在矛盾**。

> 判据：若一个角色只能用「聪明」「冷酷」「善良」概括，设计还太薄。

### 2. 核心性格必须能预测行为

主角的核心性格要能回答：

- 压力下他**首先**做什么
- 他**拒绝承认**什么
- 他把什么**过度使用**当作防御
- 他会**重复**犯哪一类错
- 哪一种诱惑**对他一定有效**

不要把性格存成形容词集合，要翻译成**行动模式**。

### 3. 压力反应是必填项

主体人物在压力升高时的反应要预先记录：**攻击 / 退缩 / 开玩笑 / 过度控制 / 过度坦白 / 更用力隐瞒**。

长篇尤其需要它——**弧光的变化只有在稳定的基线上才可见**。

### 4. 弧光分五阶段推进（不要写成一次性转变）

1. 防御性的自我
2. 第一道裂缝
3. 补偿性的过火
4. 被迫的承认
5. 有代价的改变，或悲剧性的拒绝

> 若两章之间没有任何阶段变化，弧光很可能停滞了。

### 5. 配角需要独立逻辑

每个反复出场的配角至少要有：**自己的欲望 / 来自世界的压力 / 与主角的关系 / 即使不在场也会推进的那条线**。

> 若配角只负责建议、救援、称赞或阻挠——重建他。

### 6. 关系设计承载人物真相

人物通过关系才变得可读。追踪：**谁看得懂他 / 谁误读他 / 谁能激活他的羞耻 / 谁在引诱他最坏的模式 / 谁让改变成为可能**。

### 7. 声音始于价值与节奏

言语特征来自：教育或社会位置 / 情绪克制程度 / 思维速度 / 用隐喻还是直白 / 对直接的舒适度。

**不必让每个角色表面上一听就不同**——区别可以来自节奏、省略与压力反应。

### 8. 大纲通过前的人物检查（不达标就退回）

- 欲望是通用的
- 障碍只来自外部
- 没有羞耻、亏欠或矛盾
- 压力下的行为未知
- 所有配角服务于同一个叙事功能

### 9. 章级人物五问（每章动笔前）

此刻他想要什么 / 他害怕被人看成什么 / 哪笔旧债或旧伤正活跃 / 这里能发生什么小的弧光增量 / 它该如何影响行为或对话。

### 10. 漂移警报

出现以下情况即可能有漂移：人物做出**情节方便**但没有过渡的动作 / 说话风格无因变化 / 欲望因为大纲需要而改变 / 重大压力没有留下情感痕迹。

## 第二部分：对话规则

### 1. 对话不能只是解释

每段重要对话至少要完成两件事：**推情节 / 显人物 / 改变关系压力 / 隐藏信息 / 间接揭示**。

> 若一句只是交代背景——压缩它，或把信息挪到别处。

### 2. 声音来自压力与位置

区分说话者靠：句子长度 / 直接程度 / 对情绪的舒适度 / 回避还是对抗的习惯 / 社会等级或教育 / **他拒绝直说的东西**。

**声音不是口头禅刷屏。**

### 3. 潜台词常强于直言

好用的手法：答错问题 / 绕着真正的话题说 / 对痛苦的事反应不足 / 用一个实际动作承载情感 / 让一方听到的比另一方想说的更多。

### 4. 沉默是对话的一部分

用沉默、打断、延迟来表现：抵抗 / 羞辱 / 算计 / 吸引 / 恐惧 / 权力不对等。

> **没有压力的沉默是空白；有压力的沉默才是对话。**

### 5. 用冲突承载说明

必须出现的信息，要挂在**分歧、赌注或地位与情感代价**上。

避免：两个人互相告知彼此早就知道的事；把作者演说伪装成角色智慧。

### 6. 节奏自查

这句能不能更短 / 最强的词是否落在末尾 / 回应是否落得太干净 / 是否该有人回避、打断或拒绝。

快节奏场景需要更干净的转折；沉重场景可以需要停顿与拖拽。

### 7. 对话要露出核心性格

主角的核心性格必须出现在言语里：防御性幽默 / 直接施压 / 过度控制 / 自我取消 / 道德说教 / 诱惑性的柔和。

> 若主角在不同情绪下听起来可以互换——重修。

### 8. 对话修订五问

各人想得到什么 / 各人在隐藏什么 / 权力在哪里移动 / 这段交流之后什么变了 / **哪一句可以删掉，因为场景已经演出来了**。

### 9. 常见失败

- 对话在**汇报**而不是在**施压**
- 所有人说着同样漂亮的话
- 情感坦白没有任何抵抗
- 把说明伪装成打趣
- 争吵之后关系毫无变化
