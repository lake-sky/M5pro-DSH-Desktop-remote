# 情节结构模板

> 摘编自 [chinese-novelist-skill](https://github.com/PenglongHuang/chinese-novelist-skill)（MIT）的 `references/guides/plot-structures.md`。

## 一、结构选择指南（先选结构，再动笔）

| 故事类型 | 推荐结构 | 章节数 |
| --- | --- | --- |
| 冒险 / 奇幻 | 英雄之旅 | 8–12 |
| 侦探 / 悬疑 | 悬疑结构 | 8–10 |
| 言情 | 言情结构 | 6–10 |
| 动作 / 惊悚 | 惊悚结构 | 5–8 |
| 心理 / 反转 | 反转结构 | 6–8 |
| 多主角 | 多线叙事 | 10–15 |
| 微型小说 | 3 章结构 | 3 |

## 二、两种通用结构

### 三幕式（适用大多数短篇）

| 幕 | 占比 | 内容 |
| --- | --- | --- |
| 第一幕 设置 | 约 25% | 建立处境与人物，激励事件 |
| 第二幕 对抗 | 约 50% | 冲突升级，尝试与失败 |
| 第三幕 结局 | 约 25% | 最终对决与收束 |

### 英雄之旅（坎贝尔式，适合冒险 / 奇幻）

经典阶段序列，适合 8–12 章的中长篇。**注意**：它是模板不是公式，机械套用会得到「可预测的故事」——这与 [principles.md](principles.md) 第 9 条「原创性高于对标崇拜」冲突时，以原创性为准。

## 三、类型结构要点

- **悬疑**：第一幕谜题出现 → 第二幕调查深入 → 第三幕真相揭示；
- **言情**：第一幕相遇 → 第二幕发展 → 第三幕和解；
- **惊悚 / 动作**（5–6 章）：危机出现 → 应对计划（计划失败、情况恶化）→ 追逐对抗（被逼入绝境）。特点是**节奏快、每章都有动作、时间压力持续存在**；
- **反转结构**：前两章建立「真实」情况 → 3–4 章出现不明显疑点 → 5–6 章第一次小反转（读者重新理解）。
  三条关键：前期埋下**看似无辜**的线索；每次反转都合乎逻辑（回看有迹可循）；避免机械降神。
- **多线叙事**：交叉剪辑模式（A 线 / B 线交替推进）或时间线模式（现在 / 过去交替）。
  **收敛原则**：各线最终必须交汇；早期看似无关的事件后来产生关联；收敛时产生「原来如此」的效果。

## 四、短篇的快速结构

| 结构 | 章节安排 |
| --- | --- |
| **3 章微型** | 第 1 章：激励事件 + 决定行动；第 2 章：尝试 + 失败 + 升级；第 3 章：最终尝试 + 成功/失败 + 结局 |
| **5 章标准** | 第 1 章：现状 + 激励事件；第 2 章：拒绝 + 跨越门槛；第 3 章：挑战 + 盟友/敌人；第 4–5 章：升级与解决 |

## 五、单章内部结构（可直接套用）

```text
开头（10%）：钩子 + 与上文的连接
发展（60%）：事件推进 + 冲突
高潮（20%）：本章最高点
结尾（10%）：悬念钩子 + 下章铺垫
```

**对照「无效章节」自查**：

```text
开头：漫长铺垫 / 背景说明
中间：日常活动 / 对话流水账
结尾：平淡结束 / 无悬念
```

> 这个对照表比正面模板更好用——写完一章，先看它像不像下面那三行。

## 六、与钩子的衔接

单章结构只解决「这一章怎么排」，不解决「读者为什么翻下一页」。后者见 [hooks.md](hooks.md) 的三段式设计法与跨章悬念弧。
