# study（研习）

小说创作的研习与记录区，汇集写作所需的三类知识素材。

## 内容分类

| 分类 | 说明 | 示例内容 |
| --- | --- | --- |
| 素材（Material） | 为写作收集的原始材料 | 场景描写、引文、轶事、历史掌故、人物原型、灵感片段 |
| 技法（Technique） | 写作手法的知识与练笔 | 叙事视角、结构布局、节奏控制、对话、伏笔、留白 |
| 文法（Author's Grammar） | 古今著名作者的文风解析 | 司马迁的笔法、曹雪芹的对话、鲁迅的冷峻、海明威的冰山风格、马尔克斯的抒情 |
