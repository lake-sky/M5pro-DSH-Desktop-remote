## 创作目标与验收

| 项 | 目标 |
| --- | --- |
| **验证什么** | 「能否写完一个完整故事」（[publishing/strategy.md](../../publishing/strategy.md) 阶段 0） |
| **篇幅** | 3000–8000 字，含标点口径（当前 4821）——**不必更长**：这一步验证的是能否写完，不是能写多长 |

| **合规** | 原创设定与表达，不模仿在世作家的标志性表达（[publishing/ai-compliance.md](../../publishing/ai-compliance.md)） |

1. **选定首投平台**：对照 [publishing/platforms.md](../../publishing/platforms.md) 的三条赛道——本篇是「科幻 + 文学性 + 零发表记录」，文学/出版流能兑现已有积累，免费流用不上；
