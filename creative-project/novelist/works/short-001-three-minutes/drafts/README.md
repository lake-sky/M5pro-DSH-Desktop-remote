# drafts（历史版本与废弃稿）

存放本作品的**整章重写前的旧版**与**废弃稿**。

## 规则

- **只归档，不删除**——这是「历史文章不丢失」的兜底；
- **命名**：`YYYY-MM-DD-<原文件名>-v<N>.md`，如 `2026-10-06-001-opening-v1.md`；
- **归档时机**：**整章重写之前**。改字、改句、调段落**不用归档**——行级历史由 git 负责（见 [../../README.md](../../README.md) 的「版本规划」）。

> 判断标准很简单：如果你准备**推翻这一章**，先归档；如果你只是**改进这一章**，直接改。
