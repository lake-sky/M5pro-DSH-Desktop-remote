# 《三分钟》人物设定

> 方法依据：[character-and-dialogue.md](../../study/technique/character-and-dialogue.md)（从**压力**建模，不从标签建模）
> 本文件是活文档；正文在 [chapters/](chapters/)。

## 一、林淑贞（母亲 / 主角）

### 压力模型（八项必填）

| 项 | 内容 |
| --- | --- |
| **显性欲望** | 再听一次女儿的声音——每周一次，不能停 |
| **隐性需求** | 被原谅。她想听女儿说「没关系」，但她**永远不会问出口** |
| **主要障碍** | 记忆是消耗品，越用越少；妹妹反对；规程三分钟 |
| **追求的代价** | 她对女儿的记忆本身（**她付账用的东西，就是她想留住的东西**） |
| **恐惧** | 忘记女儿的脸、声音、名字 |
| **羞耻点** | 女儿出事那天她在加班。女儿打来电话，她说「等我忙完」——那是最后一次 |
| **亏欠** | 那通没说完的电话。她后来永远忙完了，电话却再没响过 |
| **内在矛盾** | 她以为自己在留住女儿，实际在吃掉她 |

### 核心性格 → 行为预测

- **核心性格：过度控制**。她用「安排」对抗失控；
- 压力下**首先**做什么：把口袋里的号票掏出来数一遍（仪式化的自我安抚）；
- **拒绝承认**：她其实听得出来回声已经不对了；
- 过度使用的防御：精确、流程、计数；
- 重复犯的错：**用更珍贵的东西去付账**（003 学会「省着用」，恰恰加速了结局）；
- 对她一定有效的诱惑：**「再听一次」**。

### 压力反应

**退缩**（不说话，把听筒换到另一只耳朵）→ **过度控制**（提前想好这 3 分钟要说什么）。

### 弧光五阶段

| 阶段 | 落点 |
| --- | --- |
| 1 防御性的自我 | 001：仪式完美运转，她把一切安排得井井有条 |
| 2 第一道裂缝 | 002：忘了女儿爱吃什么 |
| 3 补偿性的过火 | 003：「省着用」——自以为聪明的自救 |
| 4 被迫的承认 | 004：系统提示语变了；操作员把话说完 |
| 5 **悲剧性的拒绝** | 005：她**听出来了**，仍然答「哎」——不是改变，是拒绝改变 |

> 第 5 阶段刻意选「悲剧性的拒绝」而非「有代价的改变」：**改变会让这个故事变成安慰奖。**

### 声音特征

句子短、少形容词、话里有话。**不说「我难过」，说「你那边冷不冷」。**
她几乎从不提问，除了那几句固定的问候——因为她害怕得到不一样的回答。

## 二、陈屿（女儿 / 回声）

> ⚠️ **关键设计**：她在故事里**就是母亲的记忆**。所以她的「性格」必须随消耗而**漂移**——最初说话像她自己，逐渐偏离，最后变成只有林淑贞才知道的东西。
> 这是 [character-and-dialogue.md](../../study/technique/character-and-dialogue.md) 的「漂移警报」反向使用：**漂移在这个故事里不是失误，是情节本身。**

| 项 | 内容 |
| --- | --- |
| 生前身份 | 二十六岁，做平面设计，一个人住在城西 |
| 性格 | 比她妈直接、爱笑、会撒娇——与母亲的克制形成反差 |
| 与母亲的关系 | 她一直在试着让母亲放松；母亲一直在忙 |
| 独立逻辑 | 她有自己的生活：加不完的班、养死过两盆绿植、爱吃辣 |
| 母亲为她付的账 | 那些「很普通的一天」（001 已埋：摔跤、创可贴） |

**她的漂移轨迹**（逐章）：
001 说话像自己 → 002 仍像，但开始少细节 → 003 偶尔说错（母亲没注意） → 004 语气变了 → 005 说出只有林淑贞知道的事。

## 三、林淑英（妹妹 / 反对者）

| 项 | 内容 |
| --- | --- |
| 独立欲望 | 把姐姐拉回生活——她怕姐姐死在姐姐自己的执念里 |
| 她自己的伤 | 她也失去过人（丈夫，五年前）。她**忘了**，并且认为这是活着的方式 |
| 代表的价值 | 「放手才是活下去」（见 [outline.md](outline.md) 主题表） |
| 与主角关系 | 她是**看得懂姐姐的人**，所以她的话最伤人 |
| 关系张力 | 她激活姐姐的羞耻点（「你就是不肯承认那天是你的错」） |
| 压力反应 | 直接、不耐烦、说完就走 |
| 声音 | 长句、善辩、带一点说教——**与姐姐的短句形成对照** |

> ⚠️ **写作警告**：她**不能**发表主题演讲（[principles.md](../../study/technique/principles.md) 第 6 条：主题要被演出）。
> 让她用行动表达：**她抢过姐姐的号票，撕了。**

## 四、实习操作员（制度的人格化）

| 项 | 内容 |
| --- | --- |
| 独立欲望 | 保住这份工作；但他有一点不忍 |
| 他见过什么 | 见过很多人这样消耗自己。他知道结局，但他不能说 |
| 他的抵抗 | 「按规定我得提醒您——」是他唯一能做的事 |
| 001 埋、004 揭 | 001 里这句话被打断；004 他终于说完，而她仍然签字 |
| 声音 | 程式化用语，偶尔漏出人味（递纸巾、记住她是「第十一次」） |

## 五、声音区分自检（[dialogue-writing-rules](../../study/technique/character-and-dialogue.md) 第 2 条）

| 角色 | 句长 | 直接程度 | 拒绝直说的东西 |
| --- | --- | --- | --- |
| 林淑贞 | 短 | 回避 | 那天的事、她想要的那句「没关系」 |
| 陈屿（回声） | 中短 | 直接 | 无（但她说的越来越不像她） |
| 林淑英 | 长 | 对抗 | 她自己的丈夫 |
| 操作员 | 短，程式化 | 中立 | 他的同情 |

> **检验法**：把四人的台词打乱，能否凭句子长度与回避方式认出来？认不出就重写。
