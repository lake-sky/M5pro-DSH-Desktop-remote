# 平台全景与选择矩阵

> ⚠️ 分成比例、签约政策、推荐机制**全部易变**。本文只给**结构与判断依据**，具体数字以平台当期官方公告为准（【待核】）。

## 一、三条赛道，三套完全不同的规则

| | 付费订阅流 | 免费广告流 | 文学 / 出版流 |
| --- | --- | --- | --- |
| 代表 | 起点中文网、晋江文学城 | 番茄小说、七猫 | 豆瓣阅读、科幻世界、出版社 |
| 收入来源 | 读者订阅分成 | 广告分成 / 买断 | 稿费、版税、奖项奖金 |
| 核心指标 | 均订、收藏、追读率 | 阅读时长、完读率、留存 | 编辑与评委判断 |
| 对开篇的要求 | **极高**（黄金三章定生死） | 高（前几章决定后续推荐） | 中（看整体完成度） |
| 更新压力 | 高（日更为常态） | **极高**（走量） | 低（可攒稿、可完本投） |
| 典型篇幅 | 长篇连载（百万字级） | 长篇连载 | 短篇 / 中篇 / 长篇 |
| 收益曲线 | 慢热，上架后爬坡 | 起步快但单价低 | 慢、单次 |
| 版权 | 通常签代理或电子授权 | 常见全版权或深度绑定 | 保留相对完整 |

**选择前先回答三个问题**：

1. **我能稳定日更多少字？**（低于 3000 字/日，就别碰免费流）
2. **我的题材有平台频道吗？**（科幻在付费流本就是小盘子）
3. **我要的是钱、读者、还是作品本身？**（三者排序不同，选择完全不同）

## 二、按「作者画像」推荐

本工作区的实际情况：**科幻 + 文学性追求 + AI 辅助 + 零发表记录**。

| 你的首要目标 | 建议路径 | 理由 |
| --- | --- | --- |
| 先验证「我能写完」 | **短篇**投豆瓣阅读 / 科幻世界 / 银河奖 | 短篇是类型的试验田；科幻短篇有明确通道，且**不要求日更** |
| 要读者与数据反馈 | 免费流开长篇 | 新作者容忍度相对高、反馈快；代价是节奏要求极端 |
| 要作品完整性与版权 | 付费流签分成，或攒稿走出版 | 保留版权，但周期长 |

> **诚实的判断**：科幻 + 文学性 + 零发表，是网文市场里**最难起步的组合**。付费流的科幻频道读者基数小；免费流更吃快节奏爽感。所以更现实的第一步是**用短篇积累发表记录**，而不是直接上百万字长篇。
>
> 另需注意：本工作区已投入大量精力做「文学性」准备（10 位作家风格蒸馏、类型史），这套积累在**文学/出版流**能直接兑现，在**免费流**几乎用不上。选错赛道等于把已有优势作废。

## 三、签约前必问的问题清单

这是最容易吃亏的地方——**合同条款的风险远大于写作本身的风险**。

| 类别 | 要问的问题 | 风险提示 |
| --- | --- | --- |
| 签约类型 | 分成 / 保底分成 / 买断？ | **买断＝卖断**：一书买断后后续收益与你无关。新人慎签 |
| 版权范围 | 只授权电子连载，还是**全版权代理**（影视 / 动漫 / 有声 / 游戏 / 外文）？ | 全版权代理常一签多年，可能锁死后续机会 |
| 年限与解约 | 签几年？什么条件可解约？违约金怎么算？ | 「签至作品完结后 N 年」是常见的长期锁定 |
| 笔名归属 | 解约后笔名归谁？读者能否带走？ | **笔名是资产**，别随手让渡 |
| 独家性 | 要求全平台独家吗？还能同时投短篇到杂志吗？ | 独家条款最容易被忽略，却最影响后续布局 |
| 结算 | 月结还是季结？有起付门槛吗？税费如何代扣？ | 直接影响现金流预期 |
| 完本义务 | 太监 / 长期断更的后果？ | 影响笔名信用与后续签约条件 |
| AI 条款 | 允许 AI 辅助吗？要申报吗？ | 详见 [ai-compliance.md](ai-compliance.md) |

## 四、冷启动的现实（以付费流为例）

| 阶段 | 关键动作 | 常见坑 |
| --- | --- | --- |
| 开书前 | **存稿 20–30 章**（约 10 万字） | 裸奔开书，一旦断更数据再也回不来 |
| 黄金三章 | 主角立住 + 核心冲突 + 一个强钩子 | 忙着铺垫世界观，读者第三章就走 |
| 新书期 | 争取编辑推荐位，保持**稳定**日更 | 更新忽快忽慢，推荐位给不出效果 |
| 上架 | 上架前后加更，冲首订 | 首订崩了很难翻盘 |
| 长线 | 稳定更新 + 卷末高潮 | 中途换风格、换主线，读者流失 |

> 新书期天数、推荐位规则、上架门槛**因平台而异且时常调整**【待核】。

## 五、本文件的下一次更新该做什么

1. 选定 2–3 个目标平台，逐条读其**当期官方作者规则**（重点：AI 条款、版权条款、独家条款）；
2. 找 2–3 位**近一年内**在该平台起步、题材与你接近的作者，观察其开书节奏与更新量（【待核】，需在平台内检索）；
3. 把结论回填本文件，并给每个易变数字标上**查阅日期**。
