# 签约与合同要点

> ⚠️ 各平台合同条款与行业惯例**差异极大且常变**。本文给的是**要看的条款清单与判断依据**，不是标准答案。具体条款以你拿到的合同全文为准【待核】。

## 一、为什么合同风险大于写作风险

- 一本书写砸了，损失的是**几个月时间**；
- 一份合同签错了，损失的是**未来几年这本书的全部可能收益**——包括你根本没想到的影视、游戏、有声改编。

且签约时你通常最缺议价能力（新人、无记录、急需认可），**而合同恰恰是你最需要议价能力的时候**。所以本文的定位是：至少在签字前，知道自己在签什么。

## 二、三种签约模式

| 模式 | 机制 | 主要风险 | 适合 |
| --- | --- | --- | --- |
| **分成**（订阅分成） | 平台与作者按比例分订阅收入 | 收益随销量浮动，前期可能很低 | **新人首选**：版权保留相对多 |
| **保底分成** | 保底稿酬 + 超出部分再分成 | 注意「**保底可抵扣**」条款——超出部分可能长期用于偿还保底 | 作品有把握、且能谈下保底时 |
| **买断** | 一次性付酬，后续收益与你无关 | **买断＝卖断**，后续再火也与你无关 | 极需现金时，**慎** |

> 常见误解：以为「买断」意味着高稿费。实际上买断单价常常**低于**分成模式的长期期望值——平台愿意买断，通常是因为它判断这本书会赚。

## 三、版权条款：最需要逐字读的部分

| 权利 | 内容 | 建议 |
| --- | --- | --- |
| 电子连载 / 信息网络传播权 | 平台主营业务 | 通常必须授权，属正常范围 |
| 实体出版权 | 纸书出版 | 可争取保留，或约定另行议价 |
| **影视 / 动漫 / 游戏改编权** | 高价值 IP 权利 | **优先争取保留**，或至少「单独授权、单独计费」 |
| 有声书 / 广播剧 | 近年增长快 | 同上 |
| 外文翻译权 | 出海（见 [../study/sci-fi-history/](../study/sci-fi-history/) 的译介通道） | 同上 |
| **全版权代理** | 平台代你运营**全部**权利 | **最大的坑**：年限长、分成低、你失去自主权。签名前务必想清 |

## 四、最容易吃亏的六个条款

1. **年限与解约**：「签至作品完结后 N 年」是常见的长期锁定。要问清：**什么时候能把权利拿回来**；
2. **笔名归属**：解约后笔名归谁？读者能否带走？——**笔名是资产**，别随手让渡；
3. **独家性**：是否要求全平台独家？能否同时投短篇到杂志？（影响 [strategy.md](strategy.md) 的多通道布局）；
4. **完本义务与违约**：断更、太监的后果；违约金怎么算；
5. **结算与代扣**：月结还是季结？有起付门槛吗？税费怎么扣；
6. **AI 条款**：是否允许 AI 辅助？是否需申报？违规后果？（见 [ai-compliance.md](ai-compliance.md)）

## 五、签约前的动作清单

- [ ] 拿到**合同全文**——不要只依据编辑的口头说明；
- [ ] 逐条核对第二节的三种模式与第三节的权利清单；
- [ ] 特别注意所有带「**代理**」「**独家**」「**自动续约**」字样的表述；
- [ ] 把疑问写成**书面问题**发回，保留沟通记录；
- [ ] 必要时找懂版权的人看一眼——**几百元的咨询费，换的是几年的权利**。

## 六、心态提醒

新人最容易在「有人愿意签我」的兴奋里草率签字。请记住：**平台愿意签你，说明它判断这本书有商业价值**——这本身就是你议价的依据。

宁可晚签一个月，也不要在没读懂的情况下签字。
