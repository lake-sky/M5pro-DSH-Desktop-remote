# publishing（发表与运营）

小说「写完之后」的事：投哪里、怎么签、怎么合规、怎么运营。

> **与 [study/](../study/) 的分工**：
> - `study/` 向内 —— **怎么写得更好**（素材、技法、文法、类型史）
> - `publishing/` 向外 —— **怎么发得出去**（平台规则、签约条款、合规红线、数据指标）
>
> 这个分界不是形式主义。[study/skills/takeaways.md](../study/skills/takeaways.md) 已经指出：「黄金三章、爽点密度、追更感」是**平台生存规则**，与文学写作的目的不同。两套标准混在一起会互相污染判断——写进 `technique/` 会毁掉技法库的纯度。

## 为什么小说家要单设这个目录

1. **发表规则会反噬创作决策**：写连载还是完本投、单本还是系列、开篇留不留悬念——这些**在动笔前就要定**，而定它们的依据在市场，不在文本。
2. **商业规则不可迁移**：平台算法与读者付费习惯的产物，换个平台就失效，不具文学上的普适性。
3. **合规是硬约束**：题材红线、AI 生成内容申报、签约版权条款——踩一条可能毁掉整本书，甚至毁掉笔名。
4. **它最容易变成拖延区**：本目录的存在意义是**服务发表**，不是积累知识。若它越长、作品越少，就是跑偏了（见下方「防跑偏」）。

## 数据可信度约定

沿用 [sci-fi-history](../study/sci-fi-history/README.md) 的三级标注：

- `【已核】`＝本轮已对着抓取到的外部来源核实；
- `【已核·常识】`＝凭领域知识给出，把握度较高但未二次确认；
- `【待核】`＝**平台规则与价格高度易变**，落笔前必须去平台官方页面复核。

> ⚠️ **本目录的平台政策、分成比例、签约条款全部属于易变信息。** 目录里记的是「**结构**」和「**要问的问题**」，不是「现在的数字」。任何一条用来做决策前，以平台当期官方公告为准。

## 防跑偏（写给未来的自己）

本工作区的已知模式是：**研究做得极好，动笔迟迟不来**。截至建立本目录时，`novelist/` 共 1772 行，全部是研究，**创作产出为 0**。

因此本目录设一条硬规则：

> **本目录每新增一篇文档，必须同时产出一段可发表级正文（哪怕只有 1000 字）。**
> 研究服务于发表；不服务于发表的研究，应当归类回 `study/` 或直接删除。

**规则执行记录**：本目录扩充至 5 篇时（[strategy](strategy.md) / [contracts](contracts.md) / [metrics](metrics.md)），同步产出了 [chapters/short-001-three-minutes.md](../chapters/short-001-three-minutes.md)（约 900 字开篇练习稿）。

> 该规则**已生效一次**。下次再想往本目录加文档时，先自问：**这次交正文了吗？**
