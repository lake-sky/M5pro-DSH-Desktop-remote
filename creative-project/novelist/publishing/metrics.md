# 数据指标与运营

> ⚠️ 各平台的指标定义、新书期规则、及格线差异极大且常变【待核】。本文给**指标含义与诊断逻辑**，不给具体数字。

## 一、先接受一个不愉快的事实

网文平台的推荐机制是**数据驱动**的：平台把有限的推荐位给**能留住读者**的书。

**「文笔好」不在算法里，「留存数据」在算法里。**

这不是说文笔无用——它决定读者**留下之后**的体验。但它**不决定算法给不给你曝光**。本工作区已有大量文学性积累（[../study/technique/](../study/technique/)、[../study/author-styles/](../study/author-styles/)），必须清楚：**这些是复利，不是首发优势**。

## 二、核心指标（付费订阅流）

| 指标 | 含义 | 为什么重要 |
| --- | --- | --- |
| **追读率** | 读者读完这章后是否继续读下一章 | **最重要**：推荐位的核心依据 |
| 收藏 | 加入书架 | 转化漏斗第一层；收藏高但追读低 = 开篇留不住人 |
| **首订** | 上架第一章的订阅人数 | 上架即定生死，后续很难翻盘 |
| 均订 | 平均每章订阅人数 | 收入的直接来源 |
| 月票 / 推荐票 | 读者主动投票 | 影响榜单与曝光 |
| 单章完读率 | 一章读完的比例 | 反映章节节奏与长度是否合适 |

## 三、核心指标（免费广告流）

| 指标 | 含义 |
| --- | --- |
| 阅读时长 | 用户在本书上的停留时间（收入基础） |
| 完读率 | 单章读完比例 |
| 留存 | 次日 / 7 日回访 |
| 广告展示与点击 | 分成来源 |

> 免费流对**量**的要求比付费流更高：它靠时长换广告，所以节奏更紧、字数更多。

## 四、新书期：最关键的窗口

- 新书期通常有平台流量扶持，**天数与规则因平台而异**，须自行确认【待核】；
- 关键动作：**稳定日更** + 争取编辑推荐位 + 开篇三章打磨到位；
- 最常见的两个自杀式操作：**更新忽快忽慢**、**开篇忙着铺垫世界观**（见 [../study/technique/chapter-craft.md](../study/technique/chapter-craft.md) 的六种致命错误）。

## 五、数据诊断表（比指标本身更有用）

| 现象 | 可能原因 | 先改什么 |
| --- | --- | --- |
| 收藏涨但追读低 | 开篇留不住人 | **前三章**：钩子与冲突（[../study/technique/hooks.md](../study/technique/hooks.md)） |
| 追读正常但均订低 | 付费点位置或上架时机问题 | 上架章节位置、卷末高潮安排 |
| 单章完读率低 | 章节太长、节奏拖 | 章节长度与内容密度（标准 3000–5000 字） |
| 各项都平庸 | 题材同质化或差异化不足 | **回到选题层面**，而不是改文笔 |
| 数据突然下滑 | 换风格/换主线/断更 | 先恢复更新稳定性 |

## 六、运营纪律（四条不可违反）

1. **不断更**——数据不可逆，断更后很难回到原有推荐节奏；
2. **不中途换风格或主线**——读者流失是瞬间的；
3. **不太监**——笔名信用比这本书重要（见 [strategy.md](strategy.md) 止损线）；
4. **不只盯文笔不看数据**——拿不到推荐位，就没人看得到你的文笔。
